# 電気工事施工管理 5択問題アプリ

GitHub Pages でそのまま公開できる、HTML/CSS/JavaScriptのみの5択学習アプリです。
既存アプリとは独立した別アプリとして作成しています。

## 収録分野

- RLC直列回路
- 一次側：単相2線式／二次側：三相3線式の変圧器一次電流
- 想定短絡点の三相短絡電流（％インピーダンス法）
- 架空配電線路の電線の水平張力
- 建設業法の穴埋め
- 電気事業法の穴埋め
  - 軽微な建設工事：500万円、建築一式1,500万円、木造住宅150m²
  - 対等な立場／合意／公正な契約／信義／履行
  - 通常必要／著しく短い／工期

## 復習パターン

- ランダム出題
- 間違えた問題を優先
- 未出題を優先
- 分野別
- 5問 / 10問 / 20問 / 全問
- 選択肢シャッフル
- 計算問題の数値可変
- 今回間違えた問題だけを即時再出題
- localStorage に累計正誤履歴を保存

## GitHub Pages への公開

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`、`style.css`、`app.js`、`README.md` をリポジトリ直下へアップロードします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch を `main`、Folder を `/(root)` にして保存します。
6. 数分後、GitHub Pages のURLから利用できます。

## 問題追加方法

`app.js` の `fixedQuestions` に固定問題を追加します。

```javascript
q(
  "一意なID",
  "law",
  "問題文",
  ["正解", "誤答1", "誤答2", "誤答3", "誤答4"],
  "正解",
  "解説"
)
```

カテゴリは以下です。

- `circuit`
- `transformer`
- `short`
- `tension`
- `law`
- `electricity`

数値可変問題は `genRLC()` などのジェネレータを追加・修正してください。

## 注意

ユーザーから提示された建設業法の文章のうち、
「注文者は、請負人に対して建設工事の施工につき…」
以降は文章が途中で終わっていたため、今回の初版にはその未完部分を問題化していません。
続きの条文・問題文が確定したら `app.js` に追加できます。

計算問題では、問題文に示した前提・近似式を使用しています。
資格試験の過去問を追加する場合は、出典・年度・問題条件に合わせて式や前提を確認してください。


## 追加収録（更新版）

### 建設業法
- 著しく不適当な下請負人・変更請求・書面による承諾
- 工程の細目・作業方法・あらかじめ下請負人の意見を聴取
- 出来形部分等の下請代金支払（1月以内、できる限り短い期間内）
- 完成通知後の検査（20日以内）
- 主任技術者・監理技術者の職務

### 電気事業法
- 保安規程の変更命令
- 主任技術者の保安上の指示
- 工事計画の認可・届出・変更
- 第一種・第二種・第三種電気主任技術者免状の監督範囲

第三種電気主任技術者については、現行の電気事業法施行規則に合わせ、
「電圧50,000V未満」に加えて「出力5,000kW以上の発電所又は蓄電所を除く」
という条件も問題に含めています。
